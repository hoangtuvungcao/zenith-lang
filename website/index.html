Get Started Today

1

Clone Repository

git clone https://github.com/zenith-lang/zenith.git
2

Build Compiler

cargo build --release
3

Add to PATH

export PATH=$PATH:$(pwd)/target/release
4

Run Your First Program

zenith run hello.zn
